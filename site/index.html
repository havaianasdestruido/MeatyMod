Blood & Bacon modding toolkit

Butcher the
game binary.

MeatyMod packs content mods, rewrites the game executable with Mono.Cecil so your .NET mod loads itself, decodes XNA's XNB, TXT and RAW assets, and puts the original file back whenever you ask. Nine commands, one .exe, no launcher.

Quickstart → Read the docs GitHub

Patch, play, undo

Everything below runs against a normal Steam install. A backup is written before the first byte changes.

cmd.exe 
:: build the suite and both bundled mods
> all.bat

:: inject a mod DLL into the game executable
> meatymod inject "game\Blood and Bacon\BloodandBacon.exe" ^
      --mod mods\QuackMenu\src\QuackMenu\bin\Release\net40\QuackMenu.dll
  Backup: game\Blood and Bacon\BloodandBacon.exe.backup
  Injected: QuackMenu.QuackMenuEntry.Inject

:: changed your mind?
> meatymod restore "game\Blood and Bacon\BloodandBacon.exe"
  Restored from backup.

What is in the box

Seven projects, two reference mods, two diagnostic tools and 79 tests.

IL injection Cecil

Two instructions appended to the game's myGame constructor hand your mod the Game instance. The patched executable is self-contained — no loader process, no runtime detour, no DLL hijack.

Asset formats XNB

A full XNB container reader with an LZX decompressor, plus parsers for the game's loose TXT assets, 16-bit RAW heightmaps, camera tracks and dialogue tables.

Safe installs SHA-256

Packages carry a checksums.txt that is verified before anything is written. Zip-slip paths are refused, oversized entries are skipped, overwritten files are backed up.

One-command undo restore

Every inject writes <exe>.backup first. meatymod restore copies it back. Content installs mirror replaced files into Backups\MeatyMod\.

Headless proof harness

ModHarness builds a shim XNA game, runs your mod's Inject and checks eighteen invariants — so you know the mod works before you launch anything.

Live verification memscan

A read-only Win32 scanner that confirms your module is loaded in the running game and that its marker strings are resident. It never writes to the process.

Two mods ship with it

Both are complete, documented reference implementations of the hook pattern — copy either one to start your own.

QuackMenu creative

An in-game boss spawner and creative-mode toggle. Opens an overlay listing four bosses, constructs the right one by reflecting over its constructor, and registers it with the game's screen manager.

The command line

One executable, nine commands. Full syntax, exit codes and examples live in the CLI reference.

CommandWhat it does
packZip a mod folder with a SHA-256 manifest, skipping build output.
installVerify checksums, then extract into the game's Content with backups.
injectPatch the game executable so one or more mod DLLs are invoked.
restoreCopy the .backup executable back over the patched one.
manifestBuild a JSON index of every asset in a content directory.
verifyValidate XNB headers across a file or tree; non-zero on failure.
parseDump a TXT, camera-track or RAW heightmap asset as text.
xnbReport header details and compression for XNB files.
checksumPrint sorted SHA-256 hashes for a file or directory.

Get it running

You need the .NET 10 SDK, a Windows copy of Blood & Bacon, and about three minutes.

  1. Clone and build

    One script builds the suite, both mods and both tools in Release.

    git clone {{ site.repo_url }}.git
cd MeatyMod
all.bat

  2. Point at the game

    The scripts expect the install at game\Blood and Bacon\. A junction works.

    mklink /J "game\Blood and Bacon" ^
  "C:\Program Files (x86)\Steam\steamapps\common\Blood and Bacon"

  3. Launch a mod

    Each launcher restores, injects and starts the game in one go.

    mods\launch\launch-quackmenu.bat

Injected code is not sandboxed

A mod DLL runs inside the game process with your full user rights. MeatyMod does not scan, sign or restrict it. Only inject mods you built or whose source you have read — the security model spells out exactly which guarantees exist and which do not.
